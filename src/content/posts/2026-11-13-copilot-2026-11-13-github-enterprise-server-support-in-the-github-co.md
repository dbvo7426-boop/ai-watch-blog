GitHub CopilotアプリのGitHub Enterprise Server(GHES)対応が、オプトインのプレビューを経て一般提供になりました。GHESアカウントを追加すると、そのリモートリポジトリ、Issue、プルリクエストをアプリ内で扱えます。

## 詳細

- **前提:** 先にGitHub.comまたはGHE.comのアカウントでサインインします。
- **設定:** 設定 > アカウント > アカウントを追加 で、GitHub Enterprise Serverを選びます。
- **バージョン:** Copilotアプリ 1.2.0以降が必要です。
- **制限:** GHESではクラウドセッションは利用できません。
