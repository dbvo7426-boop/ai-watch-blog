GitHub または Microsoft のアカウントチームと取引する企業は、GitHub Enterprise のライセンスを持つ全ユーザーに Copilot を含められるようになりました。Copilot のシート数と AI 利用量を別々に管理する代わりに、エンタープライズ予算に対する利用量の管理が中心になります。

## 詳細

- **機能:** Copilot Enterprise と同じ機能・モデルですが、シートごとの月次 AI クレジットは含まれません。
- **スタンドアロン:** GitHub Enterprise ライセンスを持たないユーザーは、Copilot Standalone で同じアクセスを月額 1 ユーザー 10 ドルで利用できます。
- **計測:** AI 利用は最初のリクエストからエンタープライズ予算に対して計測され、既存のポリシー、アラート、帰属の仕組みが使えます。含まれる利用枠の管理や追加購入はありません。
- **予算枯渇時:** コード補完と次の編集候補は予算がなくても使えます。Copilot Chat、コードレビュー、クラウド上の Copilot は利用可能な予算が必要です。シート(アクセス権)が取り除かれることはありません。
- **提供状況:** GitHub Enterprise Cloud で、GitHub または Microsoft のアカウントチーム経由で今すぐ利用可能。セルフサービスは段階的に開放され、日程は今後数週間で案内されます。現在のセルフサービス契約は影響を受けません。Copilot Business と Copilot Enterprise も引き続き購入できます。

## その後

Copilot がアドオンのシートからプラットフォームライセンスの一部になり、従量ベースのコスト管理へ移ります。調達は簡素化されますが、バンドルされたクレジット枠による予測しやすさがなくなるため、予算アラートの重要性が増します。セルフサービスの具体的な時期は、今後数週間という以外は非公開です。
