GitHubは2026年11月17日、MAI Code 2とMAI Code 2 FlashをGitHub Copilotに追加しました。どちらもエージェント型のコーディングワークフロー向けに作られています。

- **MAI Code 2**: 深いデバッグ、複数ファイルにまたがる実装、リファクタリング、リポジトリ全体にわたる推論といった複雑な作業向けの汎用コーディングモデルです。
- **MAI Code 2 Flash**: コードの説明、ピンポイントの編集、定型的な修正、素早い反復といった日常的な作業向けの、軽量でコスト効率の高いモデルです。

**対象プラン:** MAI Code 2はCopilot Pro、Pro+、Max、Business、Enterpriseで利用できます。MAI Code 2 FlashはFree、Student、Pro、Pro+、Max、Business、Enterpriseで利用できます。どちらも年間プランの対象ユーザーが利用できます。

**利用できる場所:** Visual Studio Code、Visual Studio、Copilot CLI、Copilotクラウドエージェント、Copilotアプリ、github.com、GitHub Mobile(iOS/Android)、JetBrains、Xcode、Eclipseのモデルピッカーです。

**課金と管理:** どちらも使用量ベースの課金です。リクエスト倍率は発表では示されておらず、モデルと料金のドキュメントが案内されています。BusinessとEnterpriseの管理者は、Copilot設定のモデルポリシーでアクセスを管理します。既定のモデル有効化では、管理者がグローバル既定やモデルを無効にしていない限り、新モデルは自動的に有効になります。
