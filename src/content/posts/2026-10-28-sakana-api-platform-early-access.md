Sakana AIは2026年10月28日、法人向けの「Sakana API Platform」を発表し、アーリーアクセスプログラムを開始した。同社のLLMを、管理機能とあわせてAPI経由で利用できる。

## 詳細

- **OpenAI互換API:** すでにLLM APIを呼び出しているアプリケーションは、エンドポイントの変更だけで利用できる。
- **モデル:** まずSakana FuguとSakana Fugu Ultraが利用可能。Sakana NamazuとSakana Fugu Maxは後続で提供される。これまでFuguとNamazuは単体のAPIとして提供されていた。
- **Fugu:** 複数のフロンティアモデルを組み合わせるオーケストレーション基盤モデル。ICLR 2026に採択された研究(TrinityとConductor)に基づく。ラインアップはFugu、Fugu Ultra、Fugu Max。
- **Namazu:** 日本語に特化したLLM。
- **管理機能:** 管理コンソールでの組織・ワークスペース管理(メンバー、APIキー、利用状況を一元化)、ロールベースのアクセス制御、CSVダウンロード可能な監査ログ、入力を学習に使用しない旨のデータ取り扱い条件。
- **商用条件:** 予算上限、請求書払い、MSAとDPAなどが挙げられている。料金と利用規約は未公開で、審査後に申込者へ個別に案内される。
- **今後:** 組織レベルでのより細かな権限制御を拡充する予定。

## その後

アクセスは準備が整った申込者から順次付与されるため、一般提供の時期や料金は未公表のままだ。既存モデルに、法人が通常求めるガバナンス機能を組み合わせた形で、研究主導のモデル公開から、管理された商用サービスへの一歩となる。
