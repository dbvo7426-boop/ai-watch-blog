Xcode 内蔵のコーディングアシスタントで、GitHub Copilot を直接使えるようになりました。連携はパブリックプレビューで、Xcode 27.3 beta 以降で利用できます。

## 詳細

- **もう一つの選択肢:** 既存の GitHub Copilot for Xcode 拡張機能も引き続き別の選択肢として使えます。
- **要件:** Apple Developer Downloads から入手できる Xcode 27.3 beta と、macOS Tahoe 26.6 以降の Mac が必要です。
- **設定:** Xcode > Settings > Intelligence を開き、コーディングアシスタントで GitHub Copilot を設定します。
- **対象プラン:** すべての Copilot プランに対応します。
- **フィードバック:** GitHub Copilot for Xcode リポジトリまたは Apple Feedback Assistant で受け付けています。

## その後の展開

サードパーティ拡張だけに頼らず、Xcode ネイティブのワークフローに Copilot が入ります。一般提供の時期や対応モデルの一覧は、発表では明らかにされていません。
