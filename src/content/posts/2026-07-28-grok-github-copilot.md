xAIは、コーディング向けモデル「Grok 4.5」がGitHub Copilotで利用可能になったと発表しました。日常的にVS CodeやGitHub製品を使う開発者に向けて、モデル選択画面から選べるようになります。

## 詳細

- **提供範囲**: VS Code IDE、Copilot CLI、クラウドエージェントなど、GitHub Copilotの各インターフェースのモデル選択画面からGrok 4.5を選択可能。組織によっては管理者による有効化の承認が必要な場合がある
- **モデルの特徴**: 高速でエージェント的なコーディングや複数ステップの複雑なワークフロー向けに設計され、最大50万トークンのコンテキストウィンドウ、テキスト・画像入力への対応、低・中・高の3段階の推論負荷を選択可能
- **性能傾向**: xAIの内部テストでは、VS Codeやコパイロットのターミナルベースのコーディングタスクで良好な結果を記録。特に複数ツールの並列呼び出しや自律的な行動判断を伴うタスクで強みを発揮し、探索的な作業や複雑なタスクの突破、時間的制約のあるコーディングに適するとしている
- **料金**: xAIのコンソール経由では入力100万トークンあたり2ドル、出力100万トークンあたり6ドル。GitHub Copilot上では利用量に応じた課金体系で提供される
- **対象プラン**: Copilot Pro、Pro+、Max、Business、Enterpriseの各SKUで利用可能

## 使ってみるには

- GitHub Copilot(VS Code、Copilot CLI、クラウドエージェントなど)のモデル選択メニューから「Grok 4.5」を選ぶ
- 組織アカウントの場合、管理者がCopilotの設定でモデルの有効化を承認する必要がある場合がある
- 並列ツール呼び出しを伴う複雑なコーディングタスクや、時間的制約のある作業での活用が推奨される
