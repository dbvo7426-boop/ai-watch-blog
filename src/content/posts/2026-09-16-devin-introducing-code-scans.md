Cognitionは2026年9月16日、Devin向けの新機能「Code Scans」を発表しました。「SEOを改善したい」「保守コストを減らしたい」「アプリのコンパイルを速くしたい」といった、漠然としているがゆえに着手されずバックログに眠りがちな改善目標を扱うための機能です。こうした目標は、どこから手をつけるべきかコードベース全体を調査すること自体が大仕事になるため、後回しにされがちでした。

## 詳細

- **できること**: ユーザーが大まかな目標を伝えると、Devinがコードベースを調査し、見つかった内容を評価した上で、レビュー可能なプルリクエストへと変換する。「何が問題かを見つける」作業と「実際に直す」作業の両方をカバーする
- **Agentic MapReduceアーキテクチャ**: Devin Security Swarmのために構築したのと同じアーキテクチャを4段階で運用。Plan(Devinがリポジトリを分析し、関連コードを判定するルールを設定)、Shard(該当コードを扱いやすいバッチに分割)、Map(並列エージェントが各バッチを調査し結果を報告)、Reduce(最終エージェントが結果を統合し、重複を排除して優先順位付け)という流れ
- **標準搭載のスキャン種別**: パフォーマンス最適化、データベースクエリ分析、テストカバレッジの穴、デッドコード検出、コード品質全般、アクセシビリティ対応、SEOに加え、チーム独自の基準によるカスタムスキャンにも対応
- **SEOスキャンの実例**: devin.aiとcognition.comのリポジトリに対して実行したところ44件の問題を検出し、Cognitionはその後数日かけて修正を出荷。Ahrefsのヘルススコアは87から92に上昇し、表示の遅いページは73%削減、画像のalt属性欠落も解消された
- **その他の実績としてCognitionが挙げる例**: Rustプロジェクト「Dioxus」に対するコンパイル速度スキャンでは、クリーンなデバッグビルドの時間を58.6秒から21.0秒へ(64%短縮)。またPhilips Enterprise Informaticsでのテストでは、複数リポジトリにわたりPRマージ率96%、推定700時間以上のエンジニアリング工数削減という結果が報告されている
- **利用方法**: Devinのウェブアプリ上で「/scan」と入力すれば開始でき、詳細はDevinの公式ドキュメントに掲載されている

## その後

Code Scansは、Cognitionがセキュリティ監査向けに最初に構築した並列エージェントの手法(Devin Security Swarm)を、より汎用的なコードベース調査へと拡張したものです。これによりDevinは、個別のチケットに応答する単なるアシスタントというより、漠然とした目標に対してリポジトリ全体を自律的に調査し、具体的でレビュー可能なプルリクエストを持ち帰るツールという性格を強めています。この発表は、Devinの音声通話機能をライブ音声モデルにアップグレードしたのと同じ週に行われており、9月半ばにかけてCognitionがほぼ連日のペースで新機能をリリースしていることがうかがえます。
