GitHub published its week-of-September-7 Copilot release roundup, headlined by a new Jira integration and an experimental adaptive model-routing system.

## Details

- **Jira integration in the Copilot app**: teams can turn Jira issues into action by bringing them into a shared canvas, prioritizing work, and having Copilot maintain context through investigation, implementation, and pull request preparation
- **Project HydraFusion (experimental)**: an adaptive model-orchestration system in Copilot CLI that automatically routes requests between local, cloud, and compound models, balancing performance, cost, and latency for each task
- **VS Code 1.137 agent automation**: scheduling recurring agent tasks (hourly, daily, weekly, or on-demand) entered public preview; an experimental voice mode for interactive code assistance was added; and issues/pull requests can now be reviewed directly inside the Agents window without opening the repository
- **JetBrains enterprise controls**: administrators can centrally manage sandbox configurations for Copilot in JetBrains IDEs, governing enablement, filesystem/network access, proxy settings, and developer-tool access

## What happened next

The mix of a productivity-tool integration (Jira), an efficiency experiment (HydraFusion's cost/latency-aware routing), and continued automation and governance features in VS Code and JetBrains reflects GitHub's ongoing weekly cadence of shipping across nearly every Copilot surface simultaneously.
