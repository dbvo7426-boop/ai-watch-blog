At DevDay 2026, OpenAI paired its GPT-6.1 Sol and "dots" announcements with a broader push to turn ChatGPT into a collaborative work platform, shipping a new Agents API, upgraded Codex tooling, team workspace features, and an app marketplace in a single event.

## Details

- **Agents API and Decisions API**: a new Agents API adds computer-use capability for developers building autonomous agents, alongside a separate Decisions API for agentic decision-making
- **Astra Ultrafast**: a new high-speed model made available across ChatGPT, Codex, and the API
- **Codex upgrades**: Codex Cloud Environments let developers run Codex locally, from a phone, or in the cloud using reusable, shareable development environments that start tasks faster; a new Codex CLI adds a command-line interface, and a Codex Security Cloud findings dashboard surfaces security issues; these ship to Plus, Pro, Business, Healthcare, Education, and Enterprise plans
- **Plugin Extensions**: lets third-party plugins claim a persistent spot in the ChatGPT sidebar with interactive panels and custom file-type viewers, available to all plans
- **ChatGPT Spaces and collaborative docs**: Spaces gives teams a shared workspace with a common knowledge base (Pro, Business, Enterprise; desktop/web now, mobile reading/sharing now with creation "coming soon"), paired with real-time collaborative Pages and Presentations for co-editing and commenting
- **Workplace integration**: ChatGPT becomes accessible inside Slack and Microsoft Teams via @ChatGPT mentions
- **OpenAI Marketplace**: launches with 16 partner tools including Devin, Notion, Vercel, T3, OpenClaw, and Dactyl, with cross-platform plan usage initially available to Plus and Pro subscribers
- **Sign in with ChatGPT**: a global identity option that lets users authenticate into partner tools without separate passwords
- **Privacy option**: a zero-data-retention mode with private safety processing for enterprise-sensitive workloads

## What happened next

Combined with the same-week launches of GPT-6.1 Sol and the always-on "dots" agents, DevDay 2026 marks OpenAI's clearest move yet from chatbot-plus-API toward a full workplace platform that competes directly with Slack, Notion, and Microsoft 365 as much as with rival model providers. The Marketplace and Sign in with ChatGPT features in particular point to OpenAI building an ecosystem lock-in strategy around ChatGPT as an identity and distribution layer, not just a model endpoint.
