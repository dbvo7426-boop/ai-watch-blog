GitHub's Copilot impact dashboard now breaks down engagement by individual feature rather than just showing aggregate usage.

## Details

- **What it shows**: how many active users engaged with each included feature on at least two days during a 28-day period
- **Tracked features**: code completion, agent edit, passive code review, active code review, cloud agent, CLI, and the Copilot app — seven distinct capabilities
- **Who can access it**: enterprise owners, billing managers, organization owners, and users with a custom role granting "View Copilot Metrics" permission, provided the Copilot usage metrics policy is enabled

## What happened next

The feature-level breakdown lets organization leaders see which specific Copilot capabilities are seeing real, repeated adoption versus which need more onboarding or promotion, rather than relying on a single aggregate usage figure.
