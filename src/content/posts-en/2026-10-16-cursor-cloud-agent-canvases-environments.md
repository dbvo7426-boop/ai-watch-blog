Cursor's October 16 changelog entry, "Cloud Agent Canvases and Environment Improvements," gives cloud agents the ability to build interactive, shareable canvases as part of their work, introduces a beta Environments API for programmatically managing agent runtimes, and scales cloud environments to support far larger codebases.

## Details

- **Canvases from cloud agents**: cloud agents can now produce interactive canvases as a work output, and a finished canvas can be shared with a team simply by sending its link
- **Environments API (beta)**: developers can now create and manage the cloud environments that agents run in programmatically, via API, rather than only through the UI
- **Larger, faster environments**: cloud agent environments now support up to 300 repositories, and large environments load up to 5x faster than before

## What happened next

The update continues Cursor's push to make cloud agents useful for larger, more collaborative engineering work: canvases give agents a way to produce shareable, interactive artifacts beyond plain code diffs, while the beta Environments API opens the door for teams to script and automate environment setup rather than configuring it by hand each time. Combined with the jump to 300-repository environments and faster load times, the changes target organizations running agents across large, multi-repo codebases — a continuation of the "Cursor Projects" and "Environments" work the company has been shipping through September and October 2026.
