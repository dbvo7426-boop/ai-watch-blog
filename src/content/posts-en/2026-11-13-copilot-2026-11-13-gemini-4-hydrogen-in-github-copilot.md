Gemini 4 Hydrogen, Google's latest Flash model, is now generally available in GitHub Copilot. GitHub describes it as designed for fast, efficient agentic coding, tool use and multistep workflows, and says it follows instructions better than Gemini 3.8 Flash.

## Details

- **Plans:** Copilot Pro, Pro+, Max, Business and Enterprise.
- **Where:** the model picker in Visual Studio Code, Visual Studio, Copilot CLI, the Copilot coding agent, the GitHub Copilot app, github.com, GitHub Mobile (iOS and Android), JetBrains IDEs, Xcode, Eclipse and the Copilot SDK.
- **Billing:** provider list pricing under usage-based billing. A request multiplier is not stated.
- **Rollout:** gradual; users who do not see it yet are told to check back soon.
- **Admins:** Business and Enterprise administrators manage access through the model policy in Copilot settings. With default model enablement, new models are enabled automatically unless the global default is off or the model is explicitly disabled.
