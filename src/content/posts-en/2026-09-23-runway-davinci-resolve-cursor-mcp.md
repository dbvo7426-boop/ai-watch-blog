Runway added two new integration points on September 23, 2026: a native plugin for DaVinci Resolve and a listing for Runway MCP on Cursor's Marketplace, putting its generative tools directly inside a professional color-and-edit suite and a popular AI coding environment.

## Details

- **DaVinci Resolve plugin (paid plans)**: Runway is now available directly inside DaVinci Resolve, letting editors bring Runway's generation and editing tools into an existing edit without switching to a separate tab or application
- **Runway MCP on Cursor Marketplace (all plans)**: Runway's Model Context Protocol server is now listed on Cursor's Marketplace, making it easier for developers to add Runway's generative capabilities to a Cursor workflow with a standard install rather than manual setup
- **Follows a run of MCP expansion**: the additions come less than a week after Runway made Kling video models callable through Runway MCP and gave MCP agents read-only access to workspace Brand Kits, and after Runway launched as a Grok Bot plugin

## What happened next

Between the Grok Bot plugin, Kling model access, Brand Kit references, and now a DaVinci Resolve plugin and Cursor Marketplace listing, Runway has spent September steadily distributing its models and MCP server across the tools professionals and developers already use, rather than requiring them to work inside Runway's own app. The DaVinci Resolve integration in particular puts Runway in front of a professional post-production audience that Runway's Media Router and Adobe integrations have already been courting this year.
