GitHub added telemetry controls that let enterprise administrators attribute GitHub Copilot activity to individual users within managed settings, along with configurable capture options.

## Details

- **User attribution**: enterprise administrators can now use telemetry in managed settings to attribute GitHub Copilot activity to a specific user
- **Configurable capture**: administrators can adjust what level of telemetry data is captured, giving finer control over the detail collected across an organization's Copilot deployment

## What happened next

This extends GitHub's growing set of enterprise-grade observability and governance controls for Copilot, landing alongside this same week's enterprise managed-settings enforcement update as part of a broader push to give organizations clearer visibility into how Copilot is used across their developer base.
