GitHub made Claude Fable 5.2, Anthropic's newest Fable model, generally available in GitHub Copilot for complex, multistep coding tasks across large codebases. GitHub says early testing showed Fable 5.2 solving more tasks than Fable 5.1 with fewer steps and tool calls.

## Details

- **Who gets it:** Copilot Pro+, Max, Business and Enterprise users. Rollout is gradual.
- **Where:** the model picker in Visual Studio Code, Visual Studio, Copilot CLI, the Copilot coding agent, the GitHub Copilot app, github.com, GitHub Mobile (iOS and Android), JetBrains IDEs, Xcode and Eclipse.
- **Admin policy:** Copilot Enterprise and Business administrators must enable the Claude Fable 5.2 policy in Copilot settings. It is off by default, and enabling it counts as acknowledging the data retention requirement.
- **Data retention:** Fable 5.2 requires data retention by default so Anthropic can run safety classifiers. Anthropic retains prompts and outputs, and says retained data is not used to train its models. Other Claude models except Fable 5, 5.1 and 5.2 still run under zero data retention.
- **Zero data retention:** eligible enterprises can use Fable 5.2, 5.1 and 5 with zero data retention through the end of the calendar year, under a time-bound exemption while Anthropic rolls out Enterprise Frontier Safeguards (EFS). After that, continued use requires EFS. Eligibility is decided through the GitHub account team, not GitHub Support, and approval does not enable the model automatically.
- **Pricing:** billed at provider list pricing under usage-based billing.
