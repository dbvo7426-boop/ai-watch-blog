Cursor has launched a set of Google Workspace plugins, allowing its coding agents to "read, write, and act across your Google Workspace" directly from the editor — spanning Gmail, Google Drive, Calendar, Docs, and Sheets.

## Details

- **Google Drive**: Search files and folders, retrieve content, and create and organize files
- **Gmail**: Search and read messages, compose and send emails, and manage labels and threads
- **Google Calendar**: View schedules, create and modify events, and identify available time slots
- **Google Docs**: Access and read documents, edit text, and create new documents
- **Google Sheets**: Read data ranges, update cells, and create and edit spreadsheets
- **Purpose**: Lets agents "pull context, draft and update files, and manage your inbox and calendar without leaving Cursor," extending Cursor's existing integration push (following its recent Slack and cloud-agent-environment updates) into everyday productivity tools rather than just code and chat platforms

## How to try it

The plugins can be installed from the Cursor Marketplace or via the Customize page inside Cursor. Setup guidance is available in Cursor's official documentation (cursor.com/changelog/google-workspace-plugins).
