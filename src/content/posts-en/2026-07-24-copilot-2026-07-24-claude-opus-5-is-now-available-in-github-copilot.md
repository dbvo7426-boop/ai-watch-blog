GitHub has added Claude Opus 5 — the new flagship model Anthropic announced the same day — to GitHub Copilot. The model is designed for careful reasoning, effective tool use, and reliable execution across multiple steps on complex coding tasks, and it's selectable across most major development surfaces.

## Details

- **Eligible plans**: Copilot Pro+, Max, Business, and Enterprise
- **Supported surfaces**: Visual Studio Code, Visual Studio, Copilot CLI, the GitHub Copilot cloud agent, the GitHub Copilot app, github.com, GitHub Mobile (iOS and Android), JetBrains, Xcode, and Eclipse
- **Design intent**: Tuned for careful reasoning, effective tool use, and reliable execution across multi-step coding tasks
- **Rollout**: Being rolled out gradually. Copilot Enterprise and Business administrators must enable the relevant policy in their organization's Copilot settings before users can select it
- **Billing**: Billed at the provider's API list price under usage-based billing (see GitHub Copilot's pricing page for exact rates)
- **Performance**: Early testing showed strong results on agentic workflows, autonomous code changes, and multi-tool coordination tasks. The model also includes enhanced safeguards around cyber-related content
- **Context**: The integration lands the same day as Anthropic's own Claude Opus 5 launch across Claude.ai, Claude Code, Claude Cowork, and the API, bringing the model into Copilot immediately

## How to try it

- On an eligible plan where the rollout has reached you, select "Claude Opus 5" from the model picker in any supported editor or app
- Business/Enterprise administrators must first enable the corresponding policy in their organization's Copilot settings
