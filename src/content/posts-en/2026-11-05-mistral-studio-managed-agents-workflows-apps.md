Mistral is expanding Mistral Studio, its enterprise AI platform, with managed agents and apps alongside new capabilities for workflows, enterprise context, agent observability, and evaluations. It positions Studio as the place to put Mistral Large 4 (Le Chonk) to work on business processes.

## What's new

- **Managed agents:** Agents for multi-step tasks, equipped with skills that capture team procedures, sandboxes for running code, and subagents. Hooks add custom logic at key points of execution. Studio runs the runtime, which Mistral says is the infrastructure behind millions of Mistral Vibe sessions each week, and developers set limits on the tools, data, and actions an agent can access.
- **Workflows:** Define which steps follow fixed rules, where an agent reasons, and when a person decides. Interrupted runs can resume. Teams can describe a process in Mistral Vibe to generate, test, and deploy a workflow with inspectable code. New event triggers from enterprise systems and a visual graph of each workflow's logic.
- **Apps:** Hosting, authentication, and access controls for internal applications, built from pre-approved reusable components. Apps can use agents, workflows, search indexes over enterprise documents, and shared context. Deploy with one command to a dedicated link or inside Mistral Vibe.
- **Mistral MCP server:** Lets developers build with Mistral Vibe or their existing coding agent, test locally, and deploy to Studio.
- **Observability and evaluation:** OpenTelemetry traces cover model calls, tool use, and approvals. Evaluations test changes to prompts, models, or tools against your own datasets before release.
- **Deployment:** Models and platform can run in your own cloud, VPC, or on-premises, in Mistral-hosted deployments, or a mix.

## Customers

Mistral names ABANCA, Accenture, Alten, BNP Paribas, Capgemini, CMA CGM, and Tata Consultancy Services as using Studio in production.

## What happened next

The release builds on the open-weights release of Le Chonk on October 29. Pricing and general availability terms for the new Studio features are not disclosed in the announcement.
