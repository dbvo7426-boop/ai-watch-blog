Cursor has announced an iPad app, following its existing iPhone app. It's available on all paid plans and features a layout rebuilt around the iPad's larger screen, letting users watch several agents run in parallel while reviewing code.

## Details

- **iPad-optimized layout**: Rebuilt around the extra screen space, with sidebar chats pinned so users can watch several agents run at once
- **Split-screen work**: A code review view and a chat can be displayed side by side, letting users review diffs while continuing a conversation
- **Expanded PR review surface**: The review screen now covers the full pull request — comments, checks, and approvals
- **Apple Pencil support**: A new markup feature lets users annotate screenshots directly, with precision commenting via Apple Pencil
- **Inbox**: A new feature that organizes in-progress work, items needing attention, and PRs under review, shared across iPhone and iPad
- **Multi-PR navigation**: Users can now access all pull requests created during a single chat session, not just the most recent one
- **Expanded repo support**: Bitbucket and Azure DevOps join existing GitHub and GitLab support
- **Team switching**: Users can now switch teams directly within the app

## How to try it

- Available now on all paid plans via the Cursor app on the Apple App Store
- See Cursor's official documentation for further details
