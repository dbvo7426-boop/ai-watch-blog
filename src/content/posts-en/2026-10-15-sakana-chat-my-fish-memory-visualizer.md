Sakana AI launched My Fish on October 15, 2026, a new feature inside Sakana Chat that turns the product's memory system — introduced in September — into a visual, explorable dashboard rather than a hidden background process.

## Details

- **Purpose**: My Fish lets users see what Sakana Chat remembers about them, when each memory was used, and how different memories relate to one another
- **Heatmap view**: a persistent heatmap at the top of the panel shows when memories were used and when new ones were learned
- **Overview view**: memories are grouped into categories such as profile, preferences, current projects, and interests, each showing its fact count, read frequency, and last-used time; opening a category reveals individual facts and the source conversations, with a jump-to-chat link
- **Connections view**: a map centered on the user's "fish," where memories placed closer to the center were used more recently, larger nodes are used more often, and faded nodes haven't been touched in 30+ days; lines connect memories that appeared together in the same reply
- **History view**: a chronological log of every memory read and write, with expandable entries showing exactly which facts were added
- **In-chat indicators**: while Sakana Chat is composing a response, a small chip (e.g., "Checked memory: Trip to Spain, Hiking") shows which memories it drew on; clicking it opens My Fish to that specific memory
- **Mobile behavior**: tapping a node in Connections opens a bottom drawer and recenters the graph on the selected memory, with a swipe-up gesture for full details
- **What gets stored**: memory is on by default but selective — Sakana Chat keeps ongoing response preferences, in-progress projects and goals, and useful background details, rather than full conversation logs
- **User control**: memory can be turned off entirely in Settings, and users can chat without it at any time
- **Access**: live now on web and mobile at chat.sakana.ai, under Settings → My Fish

## What happened next

My Fish is a direct follow-up to the cross-conversation memory feature Sakana Chat introduced on September 17, and it arrives just three days after Sakana's MASS recursive self-improvement research paper, continuing the lab's rapid release cadence across both research and consumer products. Sakana frames the dashboard as a first step toward more transparent AI memory, and says it plans to improve how Sakana Chat decides what to remember and how memories get updated as circumstances change, inviting user feedback on what to build next.
