OpenAI has introduced an Admin plugin for ChatGPT Work and Codex that lets workspace administrators handle routine management tasks — usage analytics, member and group management, permissions, and spending controls — directly inside ChatGPT, without switching between separate admin consoles or writing complex prompts.

## Details

- **The problem it addresses**: As workspaces grow, admins have had to navigate between separate analytics dashboards, settings pages, and reports to manage users and spending. OpenAI says this made "routine admin work slower and harder to complete consistently," which the plugin aims to consolidate into a single conversational interface
- **Usage analytics**: Admins can track activity and credit consumption across the workspace, spot where user enablement or training is needed, and see when individuals or teams are approaching their credit limits
- **Member and group management**: The plugin supports adding and removing members, updating group membership, and handling onboarding and offboarding — tasks that previously required separate workspace settings screens
- **Access and permissions**: Admins can review a user's effective permissions, diagnose access issues (e.g., why someone can't reach a specific model or feature), and manage feature or model access by role or group
- **Usage limits and spending**: The plugin allows admins to adjust usage limits for individual members, groups, or the whole workspace, and to review, approve, or deny spending requests with relevant context surfaced automatically
- **Workflow integration**: The plugin can automate recurring administrative checks and high-volume requests, and integrates with Slack and Microsoft Teams so approval workflows can happen where admins already work
- **Guardrails**: The plugin operates strictly within a workspace's existing role-based permission structure — it does not grant admins any broader access than they already have — and provides transparent tracking of what changes were requested and their outcomes

## What happened next

- Admins can enable the Admin plugin from ChatGPT workspace settings and install it from the Plugins directory in the web or desktop app
- OpenAI has not published a specific rollout timeline beyond describing the plugin as newly introduced for ChatGPT Work and Codex workspaces
- Full details are available at https://openai.com/index/introducing-admin-plugin
