OpenAI announced it will acquire Pierre Computer Company, Inc., the company behind Code Storage and a family of open-source developer tools. OpenAI says anyone who has browsed files or reviewed a change in the Codex app has already used Pierre's Trees and Diffs libraries.

## Details

- **Trees and Diffs:** Trees lets developers navigate a project's files quickly; Diffs shows what changed. Diffs also has an Edit mode that lets a reviewer fix a line right where the problem is spotted.
- **Highlights:** Pierre recently released Highlights, a fast syntax highlighter that updates as a developer types or an agent streams code.
- **Code Storage:** A service, with an API designed by the same team, that lets apps store code and track its history using Git.
- **Direction:** OpenAI wants to adapt Git workflows to how teams work with coding agents, from the first branch an agent creates to deployment, and make Codex the place where developers and agents take on ambitious projects. It ties this to Pando, its in-house source control backend, which it described earlier the same week.
- **Open source:** Pierre's open-source projects will remain open source and OpenAI will keep contributing to them. Code Storage customers can keep using it after closing while OpenAI works to bring its features into Codex.
- **Closing:** Subject to customary conditions, including regulatory approvals. Until then the two companies remain separate and independent. Deal terms were not disclosed.
