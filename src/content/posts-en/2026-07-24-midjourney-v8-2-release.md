Midjourney released its new image model, V8.2, as the default model on July 24, 2026. It's the full release of the model that had been available as a preview via the `--preview` flag since June 25, and the update focuses on improved aesthetic quality and more accurate personalization.

## Details

- **Improved aesthetics**: Images are tuned to be more creative, bold, sophisticated, and edgy, with a significant reduction in the low-quality outputs that could previously occur unpredictably for certain prompts
- **More accurate personalization**: The model better understands individual user taste, with the improvement especially noticeable for profiles that have a large number of ratings
- **Expanded reference image pool**: When creating a new Personalization profile for V8.2, users now have access to a much larger and improved pool of reference images to choose from
- **Rollout**: Following the preview period that began June 25, V8.2 has now graduated to become the new default model, replacing V8.1

## How to try it

- Just submit a prompt as usual — V8.2 is applied automatically as the default model, no extra parameters needed
- Midjourney recommends trying both existing and newly created Personalization profiles with V8.2
- Available on both the Web and Discord interfaces
