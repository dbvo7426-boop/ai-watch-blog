xAI has added a new mode called "Build Mode" to the main Grok app. Tell Grok an idea, and it builds a working version live in your chat; once it's ready, you can publish it to a link anyone can open. It's rolling out now in Early Beta for SuperGrok Heavy subscribers on web, iOS, and Android.

## Details

- **How to access it**: Select "Build" from the mode switcher on grok.com or the Grok mobile app — no installation or setup required
- **Live iteration**: Users can request layout changes, new features, or styling tweaks conversationally, with the app updating live in the chat preview
- **Publishing**: Finished apps can be published to a `grok.me` link or a custom domain, and shared with a team or the public
- **What it can build**: Websites (landing pages, portfolios, business sites), apps (planners, trackers, calculators, simulations, utilities), games (racers, puzzles, interactive 3D worlds), and interactive dashboards with data connectors for business analytics
- **Under the hood**: Apps run on the full "Grok Build" coding agent, using its subagents, browser-use tools, and Grok Imagine's image generation
- **Developer path**: Generated app source code can be exported to GitHub to keep developing manually
- **Availability**: During Early Beta, limited to subscribers of the $300/month "SuperGrok Heavy" tier

## How to try it

- Subscribe to SuperGrok Heavy, then select "Build" from the mode switcher on grok.com or the Grok app
- Describe what you want to build in plain language, iterate conversationally, then publish a shareable link when it's ready
