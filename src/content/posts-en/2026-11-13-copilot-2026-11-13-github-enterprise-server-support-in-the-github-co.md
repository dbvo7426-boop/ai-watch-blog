GitHub Enterprise Server (GHES) support in the GitHub Copilot app is now generally available, after being an opt-in preview. You can add a GHES account and work with its remote repositories, issues and pull requests in the app.

## Details

- **Prerequisite:** sign in with a GitHub.com or GHE.com account first.
- **Setup:** Settings > Accounts > Add account, then choose GitHub Enterprise Server.
- **Version:** requires Copilot app 1.2.0 or later.
- **Limitation:** cloud sessions are not available for GHES.
