Lovable shipped three changelog updates on October 1, 2026: real-time voice conversations for apps built on the platform, an EU-only AI processing option for Enterprise workspaces, and IP allowlisting for workspace API keys.

## Details

- **Live Voice Conversations (GPT Live)**: builders can now add real-time, interruptible spoken conversations to their app's AI features; a user describes the kind of voice experience they want, such as a voice tutor or spoken assistant, and Lovable configures it. The feature requires TanStack Start and consumes credits to run
- **EU Data Processing**: Enterprise plan admins and owners can enable EU inference from the workspace's Privacy & security settings, routing AI model requests through EU-based providers during both development and in published apps; some models and features are unavailable under this setting, and it increases credit consumption
- **IP Allowlisting for API Keys**: Business and Enterprise admins can restrict a workspace API key to an allowlist of IP addresses and ranges, uploaded as a CSV file at key creation or added later from an existing key's menu; requests from addresses outside the list are rejected

## What happened next

The three updates land the same day and skew toward enterprise trust and compliance alongside a consumer-facing creative feature. Live Voice Conversations extends Lovable-built apps beyond text and visual interfaces into spoken interaction, while EU data residency and API key IP restrictions address data-sovereignty and access-control requirements that are typically prerequisites for larger enterprise customers evaluating AI app-building platforms.
