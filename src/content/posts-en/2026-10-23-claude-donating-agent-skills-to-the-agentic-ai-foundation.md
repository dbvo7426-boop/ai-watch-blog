Anthropic is donating Agent Skills, the open standard that gives AI agents specialized knowledge and workflows, to the Agentic AI Foundation (AAIF) under the Linux Foundation. Anthropic says more than 70 agent platforms, including ChatGPT, Cursor, GitHub Copilot and VS Code, have integrated the standard since it was published in December 2025.

## Details

- **What a skill is:** A folder containing a SKILL.md file that teaches an agent a task or domain, with any scripts or reference material needed. Skills came out of work on Claude Code.
- **Adoption:** Anthropic reports 1 million skills published and nearly 280 million installs.
- **What is donated:** The Agent Skills name and logo, the GitHub organization and the agentskills.io domain. The standard remains usable and open to contributions without joining the AAIF.
- **Governance:** The AAIF was co-founded last year with Block and OpenAI, and received the Model Context Protocol. Engineers from Anthropic, Google, OpenAI and others will maintain the standard as individuals, with David Soria Parra and Mahesh Murag as Lead Maintainers.
- **Proposed roadmap:** Versioned releases, a formal proposal process, and security guidance for people who write and install skills.

## What happened next

Moving the standard to a neutral home mirrors what happened with MCP and aims to reduce vendor-lock-in concerns for cross-vendor skill formats. The roadmap is only proposed, and no dates were given. Feedback on specification changes is collected via the project's Discord and GitHub.
