Devin's release notes dated November 13, 2026 list a batch of interface, review and admin changes.

## Details

- **German UI:** Deutsch is available in Preferences, using standard engineering terms.
- **Session file editor:** Files save manually with Cmd/Ctrl+S. Unsaved tabs show a dot, and closing a tab with unsaved edits asks first. Devin is told which files you saved.
- **Artifacts rail:** Workspace tabs no longer open automatically. A compact rail beside the chat lists outputs such as pull requests, previews and Plan.
- **Agent/Ask switch:** moved into a dropdown inside the composer, with per-mode options for each side.
- **Review analytics:** shows whether findings were fixed, rejected or ignored, including results for each custom reviewer's instruction versions.
- **Devin Review:** adds GitLab merge train support, skips collapsed files in Find by default, and lets you press `m` to enable auto-merge.
- **Security:** you can unlink Devin from a finding so it can be fixed again, and Copy as Markdown now includes validation and review reasons.
- **Admin controls:** organizations can turn off automatic CI follow-up and session details in PR descriptions, and non-enterprise organizations can upload an organization picture.
- **Plugins:** MCP servers can offer region choices (Datadog uses this), and existing installs move to a new server URL without reconnecting.
- **Availability and pricing:** undisclosed in the release notes.

## What happened next

The notes also describe earlier changes that week, such as the redesigned Devin Review page reaching all organizations on November 12. This entry covers only the November 13 items.
