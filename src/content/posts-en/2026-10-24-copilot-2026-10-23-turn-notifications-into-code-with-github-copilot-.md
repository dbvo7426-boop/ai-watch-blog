On October 23, 2026, GitHub announced a new GitHub app for Microsoft Teams, previously called GitHub notifications, that combines Teams notifications with GitHub Copilot so teams can act on issues without leaving their conversations.

## Details

- **Notifications:** GitHub updates can be delivered to channels, group chats or private chats.
- **Taking action:** Mention @github in Teams to have Copilot work on an update.
- **Example workflow:** A bug report arrives in Teams, you mention @github, Copilot investigates, fixes the bug and opens a pull request, and the team reviews, tests and merges it.
- **Existing users:** If GitHub notifications is already installed, update the app; current notification features keep working.
- **Legacy app:** The old GitHub app will be renamed "GitHub (deprecated)" and retired on November 16. To keep using Copilot in Teams, install the consolidated app, mention @GitHub, connect your GitHub account and select a repository when prompted.

## What happened next

The consolidation folds notification and agent features into a single Teams app, with a firm retirement date for the old one. Teams using the legacy app should migrate before November 16 to avoid losing Copilot access in Teams. GitHub opened a discussion thread in the GitHub Community for feedback.
