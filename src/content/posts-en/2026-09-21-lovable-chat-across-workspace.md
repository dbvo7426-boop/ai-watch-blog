Lovable shipped a wide-ranging update on September 21, 2026, adding new ways to talk to Lovable both inside and outside a project, plus a batch of admin-facing controls.

## Details

- **Chats outside projects**: a new "Chats" surface (at lovable.dev/chats) offers private conversations to think through an idea, ask about existing apps and the workspace, work in connected tools, create files, and send the result to a project when ready to build — including voice conversations
- **Chat mode inside projects**: the project mode picker gains a chat option where Lovable discusses the currently open app without changing its code
- **Jev for typed decisions**: apps built with Lovable can use "Jev Latest," a model that returns a category, a score, or a yes/no probability instead of generated text — aimed at use cases like ticket triage or content moderation
- **Lovable in Telegram**: the Telegram bot integration now works with connected tools like Slack, Notion, and HubSpot, showing permission requests before it modifies any data
- **Default design systems for groups**: Business and Enterprise admins can set a default design system per group, which members can still override before creating a project
- **Centralized agent permissions**: a new settings page lets users review and modify connector permissions for their agents in one place

## What happened next

The update pairs a new conversational surface — chat that isn't tied to editing a specific app's code — with governance features aimed at larger teams, such as group-level design defaults and centralized permission review. It's the second of three Lovable changelog updates in the same week, following the Files collections redesign on September 20 and preceding the Parallel research connector added September 22.
