GitHub deprecated four models across all GitHub Copilot experiences as of October 2, 2026.

## Details

- **Deprecated models**: Gemini 3.5 Flash, Gemini 3.6 Flash, Kimi K2.7 Code, and Claude Opus 4.7
- **Recommended replacements**: Gemini 3.8 Flash for both Gemini versions, Kimi K3 for Kimi K2.7 Code, and Claude Opus 5.5 for Claude Opus 4.7
- **Scope**: applies across all GitHub Copilot experiences, including enterprise-managed deployments
- **What doesn't change**: deprecated models are not automatically removed; GitHub advises updating workflows and integrations to use supported models, and enterprise administrators may need to enable access to the replacements through model policies

## What happened next

The deprecations clear out older model tiers as GitHub continues rolling 2026's newer generation (Opus 5.5, Gemini 3.8, Kimi K3) further into Copilot's default lineup, consistent with the steady cadence of model refreshes GitHub has run alongside each new frontier release this year.
