Lovable pushed a wide batch of integration-focused updates on September 10, 2026, expanding where and how builders can connect Lovable projects to outside tools.

## Details

- **Bitbucket Cloud sync**: projects can now connect to a Bitbucket workspace for two-way code synchronization, joining Lovable's existing GitHub and GitLab support
- **Cloudflare API connector**: apps can connect to Cloudflare to manage zones, DNS records, and Workers directly
- **New chat connectors**: Canva and Wispr Flow join Lovable's list of prebuilt chat connectors, covering design and voice-note-taking use cases
- **Lovable MCP works with Grok**: Lovable apps can now be reached from Grok through a custom MCP connector, in addition to previously supported assistants
- **Credits breakdown**: the usage dashboard now splits how many Build credits go toward media generation versus other work
- **Mobile invite sharing**: users can now share their referral invite link directly from a phone browser
- **ZIP file preview**: uploaded ZIP files now show their contents before Lovable processes them

## What happened next

The Bitbucket and Cloudflare connectors round out Lovable's source-control and infrastructure integrations for teams that don't standardize on GitHub or Vercel-style hosting, while the Grok MCP support extends Lovable's reach into another AI assistant ecosystem following earlier ChatGPT and Claude integrations. Full changelog entries are at docs.lovable.dev/changelog.
