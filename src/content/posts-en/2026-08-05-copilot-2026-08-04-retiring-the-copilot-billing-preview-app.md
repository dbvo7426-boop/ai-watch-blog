GitHub has retired the GitHub Copilot Billing Preview app, an early tool for reviewing Copilot spend, since its reporting has now been superseded by more complete views built directly into GitHub's billing settings.

## Details

- **What it was**: The Copilot Billing Preview app helped users understand their bills during the shift to usage-based Copilot billing
- **Why it's retired**: GitHub's billing settings now provide a more complete view than the app's reports could show, including user-level budgets, cost centers, and usage pool allocation
- **Where to go instead**: The **AI usage** page in GitHub billing settings, which lets you view, group, filter, and export AI credit data
- **Budget controls**: Organizations and enterprises can set user-level budgets to cap individual spending
- **Raw data access**: Usage reports and the billing API remain available for extracting raw usage data

## How to try it

- Head to your GitHub billing settings and open the **AI usage** page to review Copilot spend
- Set up user-level budgets if you need to cap spending across your organization or enterprise
- Use the billing API or usage reports if you need raw data for your own dashboards
