Replit's October 23 update bundles five changes, led by a Monitoring Agent that watches published apps, investigates production issues, and tries to fix them. The release also covers agent-suggested skills, sharing of chats and assets, Stripe Atlas incorporation help, and a grace mode for apps at zero credits.

## Details

- **Monitoring Agent**: an autonomous agent that investigates production issues using the app's logs and metrics, then attempts and validates fixes. Monitoring alerts and auto-fix can be turned on so it triages in the background. An experimental auto-republish setting can publish validated fixes automatically; otherwise users review and publish fixes themselves.
- **Skills creation and updates**: Agent can suggest new reusable skills, or improvements to existing ones, based on conversations and projects. Each suggestion must be approved before it is saved to the workspace's skills library.
- **Chat and asset sharing**: a whole chat or a single asset can be shared with selected teammates or the whole workspace. Chat access is read-only and includes the chat's assets and development URLs. Development URLs open live servers rather than isolated previews, so users should check what their server exposes before sharing.
- **Stripe Atlas**: Agent can help incorporate a business through Stripe Atlas, with 20% off when incorporating through Replit.
- **Running apps at zero credits**: eligible top-up customers can keep published apps running at zero credits, up to an overage limit. Paid Agent pauses, Free mode stays available, and warning emails are sent before suspension. New credits repay the overage first.

## What happened next

The Monitoring Agent moves Replit's Agent from building apps toward operating them after launch. Keeping a human approval step by default, with auto-republish labeled experimental, suggests Replit is cautious about unattended production changes. The sharing note about live development URLs is a practical warning that shared chats can expose running servers.
