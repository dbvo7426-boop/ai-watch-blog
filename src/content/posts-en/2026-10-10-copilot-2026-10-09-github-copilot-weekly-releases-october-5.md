GitHub published its weekly Copilot release roundup for the week of October 5, bundling several account, CLI, and VS Code updates.

## Details

- **Claude Haiku 5.5**: now available to Copilot Pro, Pro+, Max, Business, and Enterprise users
- **Local sandboxing (GA)**: restricts what agents can reach — files, networks, and credentials — across Copilot CLI, the Copilot app, and VS Code sessions using Agent Host, at no extra cost
- **Separate accounts in the Copilot app**: lets users pair one GitHub account for their Copilot license with a different account for accessing repositories, such as an enterprise-provided license used alongside a personal account
- **Local model discovery in Copilot CLI**: the `/model` command lists models from a running local Ollama instance alongside configured cloud models
- **Side-by-side agent sessions in VS Code 1.141**: the Agents window can arrange sessions in a grid to compare results or track multiple tasks at once
- **Worktree cleanup in VS Code 1.141**: an "Open worktree cleanup" option in chat shows how much disk space inactive session worktrees use and lets users choose which to delete

## What happened next

Most individual items in this roundup — Claude Haiku 5.5, local sandboxing GA, and local model discovery — were already covered here as standalone releases; the genuinely new items are the separate-account support and the VS Code 1.141 session-management features (side-by-side sessions and worktree cleanup), continuing GitHub's incremental polish of multi-session agent workflows.
