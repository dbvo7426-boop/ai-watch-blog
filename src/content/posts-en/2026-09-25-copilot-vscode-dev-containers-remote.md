GitHub's week-of-September-21 Copilot roundup bundled the week's major releases — Claude Opus 5.5, GPT-6 Sol/Luna, and Grok 4.7 reaching Copilot, plus local sandboxing and Slack/Teams updates — alongside a VS Code update not covered elsewhere.

## Details

- **VS Code 1.139 Dev Container support**: Copilot agents can now execute inside Dev Containers across SSH, Tunnel, and WSL remote connections, extending agentic workflows to remote development setups that previously weren't supported
- **Session organization**: a compact view and filtering options for managing agent sessions
- **Layout preview**: a new preview option lets users choose between separate or unified chat panes

## What happened next

The Dev Container support closes a gap for developers who do remote development over SSH, Tunnel, or WSL rather than working directly on a local machine, letting Copilot's agent features follow them into those environments.
