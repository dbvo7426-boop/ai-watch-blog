Sakana AI has upgraded Sakana Translate to run on a new generation of its Japanese-focused Namazu model, the same generation it recently brought to Sakana Chat, and says the update wins head-to-head comparisons against every rival system it tested more than half the time.

## Details

- **What changed**: the translation model behind Sakana Translate was swapped for a new generation of Sakana Namazu, built on "a refreshed base model and improved training methods" aimed at deepening Japanese language understanding. This same new Namazu generation now powers Sakana's API, Sakana Chat, and Sakana Translate.
- **About Namazu**: Sakana describes Namazu as "a model series developed with a strong emphasis on understanding the Japanese language and the culture and context behind it."
- **Benchmark claim**: using Sakana's own evaluation method, TransEvalnia, the company ran 160 Japanese-to-English translation tasks head-to-head against competing systems and reports that "Sakana Translate's output was judged the better translation more than 50% of the time against every system we compared with."
- **Languages**: bidirectional translation between Japanese, English, and Chinese.
- **Features**: translation of texts up to roughly 5,000 characters with real-time streaming output, a Proofread mode, and an Ask mode for follow-up questions about a translation in context.
- **Price and access**: Sakana Translate remains free; users just need to create an account to use all three features.
- **Release date**: August 21, 2026.

## What happened next

The update means all three of Sakana AI's Namazu-powered products — the paid API (launched Aug 3), Sakana Chat (updated Aug 13), and now Sakana Translate — run on the same new model generation, consolidating Sakana's push to make its Japanese-language specialization available across its whole product line rather than one endpoint at a time.
