You can now work with GitHub Copilot directly in Xcode's built-in coding assistant. The integration is in public preview, available starting with Xcode 27.3 beta.

## Details

- **Another option:** The existing GitHub Copilot for Xcode extension remains a separate choice, so you can pick the workflow you prefer.
- **Requirements:** Xcode 27.3 beta from Apple Developer Downloads and a Mac running macOS Tahoe 26.6 or later.
- **Setup:** Open Xcode > Settings > Intelligence and set up GitHub Copilot in the coding assistant.
- **Plans:** All Copilot plans are supported.
- **Feedback:** Via the GitHub Copilot for Xcode repository or Apple Feedback Assistant.

## What happened next

This brings Copilot into the native Xcode workflow rather than relying only on a third-party extension. A general availability date and the list of supported models are not disclosed in the announcement.
