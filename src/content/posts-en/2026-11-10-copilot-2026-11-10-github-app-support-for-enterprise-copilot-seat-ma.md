Enterprise GitHub Apps can now call the enterprise-level Copilot seat management APIs, which control which users and enterprise teams are assigned Copilot seats.

## Details

- **Permission:** access requires a new enterprise fine-grained App permission named Enterprise Copilot license management.
- **API:** the linked documentation covers the Copilot user management REST API, pinned to API version 2026-03-10.
- **Not described:** installation steps, token types, request examples and rollout details are undisclosed in the changelog; they are in the linked REST documentation.
