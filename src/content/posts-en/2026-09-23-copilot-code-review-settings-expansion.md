GitHub extended Copilot code review's personal configuration options to Business and Enterprise plans, which previously lacked the settings available to Pro, Pro+, and Max subscribers.

## Details

- **Personal settings**: a dedicated code review settings page now lets any user turn on automatic reviews that trigger when they create a pull request, configure separate controls for draft PRs and new pushes, and set a default review effort level of Lite or Balanced
- **Enterprise-level defaults**: administrators can set organization-wide review effort defaults that cascade to organization-owned repositories, while still allowing individual overrides at the organization and repository levels

## What happened next

The change closes a configuration gap between individual and enterprise plans, giving Business and Enterprise users the same personal control over review behavior that had been Pro-tier-only, while still letting admins set organization-wide defaults on top.
