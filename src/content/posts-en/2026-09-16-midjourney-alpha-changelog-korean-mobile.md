Midjourney published an alpha changelog dated September 16, 2026, adding Korean-language support to the alpha build and shipping a wide-ranging set of editor, mobile, and organization fixes on alpha.midjourney.com.

## Details

- **Korean language support**: the alpha build now supports Korean, and Midjourney says it is recruiting contributors to help expand the product into additional languages
- **Editor changes**: the V8.2 editor's prompt interface now shows "What would you like to change?" when images are attached, draft batches display source images in a grid with hover previews, and the previous Upscale button has been replaced with an Enhance option; "Add to Folder" now works from the editor even with no existing folders
- **Mobile and tablet work**: pages now use the full screen width, content no longer hides behind the bottom bar, screen-rotation bugs were fixed, menus stay accessible, uploads gained a delete option via a three-dot menu, and search now opens the keyboard immediately — Midjourney still recommends production over Alpha for mobile use
- **Prompt bar fixes**: a single backtick no longer freezes tabs, `--no a, b`-style comma lists now process fully, text wraps instead of clipping, and pill content persists during previews; the search drawer now surfaces frequent and recent references for filtering
- **Organization features**: folders can be dragged with a collapsed sidebar, folder links survive renaming, external-site moodboard linking was enabled, and Organization became a top-level navigation item with hover flyouts
- **Bug fixes**: the Animate feature was restored after breaking, along with general performance improvements and refined keyboard navigation

## What happened next

This is Midjourney's third documented alpha changelog since the start of September, following updates on September 2 and September 3, and continues the team's pattern of shipping incremental UI, localization, and reliability fixes to the alpha build ahead of any broader rollout. The Korean-language addition marks Midjourney's most concrete step yet toward multilingual support, alongside its ongoing push to recruit outside contributors for further localization work.
