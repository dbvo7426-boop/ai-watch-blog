GitHub made Anthropic's Claude Opus 5.5 available in GitHub Copilot, positioned for agentic coding, long-running agentic tasks, and knowledge work.

## Details

- **Efficiency gain**: resolves tasks comparably to Claude Opus 5 while using significantly fewer steps and tokens
- **Built-in watermarking**: includes text watermarking that doesn't affect quality or cost
- **Error recovery**: demonstrates strong recovery from errors during complex, multistep workflows
- **Supported surfaces**: Visual Studio Code, Visual Studio, Copilot CLI, the coding agent, github.com, GitHub Mobile (iOS/Android), JetBrains IDEs, Xcode, and Eclipse
- **Eligibility**: Copilot Pro+, Max, Business, and Enterprise subscribers, with gradual rollout and admin-controlled access via model policies for Business/Enterprise

## What happened next

Opus 5.5's efficiency-focused positioning — same quality, fewer steps and tokens — mirrors the cost-per-task framing OpenAI used for GPT-6 Sol and Luna the same week, suggesting model providers are converging on efficiency, not just raw capability, as the next competitive axis for coding-focused models.
