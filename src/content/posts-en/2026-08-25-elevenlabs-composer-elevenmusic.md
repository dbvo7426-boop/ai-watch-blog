ElevenLabs has launched Composer, a new song-editing tool inside ElevenMusic that breaks track creation into independent sections instead of treating a song as one indivisible generation. Creators can now rework a chorus, swap in new lyrics for a bridge, or regenerate an intro without disturbing the rest of the track.

## Details

- **Section-level editing**: Each section of a track — verse, chorus, bridge, outro — can be edited and regenerated on its own, leaving the rest of the song untouched
- **Per-section controls**: Style, tempo, energy, instrumentation, key, and duration can all be adjusted independently for a single section
- **Custom lyrics anywhere**: Users can add or rewrite their own lyrics for any section at any point in the process, rather than only at the initial prompt stage
- **Multiple takes**: Composer can generate several versions of the same section so creators can audition and compare them before picking a favorite
- **Structural rearrangement**: Sections can be swapped, doubled (e.g., repeating a chorus), extended, or reordered as a song develops
- **Flexible starting points**: A project can begin from existing lyrics, an existing track, a text prompt, or a blank page

The release follows ElevenLabs' broader push into AI music tools this year, including the Eleven Music API and earlier inpainting-style editing capabilities, as the company competes with Suno and Udio in AI-generated music.

## How to try it

- Composer is live now inside ElevenMusic at elevenmusic.io/compositions
- No separate pricing tier was announced for the feature at launch; availability follows existing ElevenMusic/ElevenLabs account access
