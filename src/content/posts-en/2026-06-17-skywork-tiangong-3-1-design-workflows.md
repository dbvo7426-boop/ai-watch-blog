Kunlun Wanwei has announced a new version of Tiangong, "Tiangong 3.1 (Skywork 3.1)." The release adds two new capabilities: Skywork Design, which moves design work onto a canvas, and Dynamic Workflows, which runs large numbers of sub-agents in parallel to handle big tasks — aiming to push AI output from "demo" to "production-ready."

## Details

- **Skywork Design**: Instead of a conversational chat box, design work happens on an expandable canvas. Users can view multiple pages, UI elements, and design systems at once, upload brand guidelines or component specs to maintain consistency, and export finished designs as web pages, PDFs, Figma files, or code packages
- **Dynamic Workflows**: Built for large-scale, multi-step tasks. It automatically decomposes and distributes work across dozens or hundreds of sub-agents running in parallel, with cross-validation to ensure accuracy. Progress is saved at checkpoints, so interrupted projects can resume rather than restart from scratch
- **Intended use cases**: Bulk generation of landing pages, content migration, code repository reviews, and other high-volume, repetitive work
- **Track record**: After the previous "Tiangong 3.0" launch, revenue tied to Tiangong's super-agent tripled within a month. Heavy users average more than 40 interaction rounds per project, with website creation being the most-engaged use case

## How to try it

- Tiangong 3.1 launched simultaneously in domestic and overseas markets and is available via the official Skywork/Tiangong sites (skywork.ai / tiangong.cn)
