GitHub moved "Copilot harness" — the agentic framework underpinning GitHub Copilot for JetBrains — to general availability, alongside a public preview of a built-in JetBrains MCP server.

## Details

- **What's new**: a built-in JetBrains MCP (Model Context Protocol) server enters public preview, letting agent workflows tap into IDE-native capabilities directly; a `/review` integration is now accessible right inside JetBrains without switching apps, and plugin updates now surface a "What's New" tab automatically
- **Usability improvements**: better model search and management with resizable columns, improved debug-workflow sorting and token-usage filtering, better handling of long tool outputs in chat, and multi-root workspace customization discovery across all project folders
- **Reliability fixes**: more stable account detection and sign-in, improved MCP schema and tool-state handling, better session continuity after resuming, restored file/folder references in chat inputs, and fixed WSL worktree startup issues

## What happened next

With the harness now GA, JetBrains reaches parity with the agentic foundation GitHub has already shipped to VS Code and Visual Studio, positioning JetBrains users to pick up future Copilot agent features on a similar timeline going forward.
