GitHub has deprecated two models — Gemini 2.5 Pro and Gemini 3 Flash — across all GitHub Copilot experiences as of July 31, 2026, including Copilot Chat, inline edits, ask and agent modes, and code completions. Users need to switch to the recommended replacement models.

## Details

- **Deprecated models and replacements**: Gemini 2.5 Pro should be replaced with Gemini 3.1 Pro (Preview); Gemini 3 Flash should be replaced with Gemini 3.6 Flash
- **Scope**: The deprecation applies across all GitHub Copilot experiences, including Copilot Chat, inline edits, ask and agent modes, and code completions
- **Required action**: Users and admins need to update their workflows and integrations to use the recommended alternative models. Copilot Enterprise admins need to enable access to alternative models through their model policies in Copilot settings
- **No manual removal needed**: There's nothing to manually remove, but the deprecated models simply stop working once the deprecation takes effect
- **Support**: GitHub Enterprise customers with concerns are encouraged to contact their account manager, and further model documentation is available in GitHub's support resources

## How to try it

- Check the Copilot model picker for any workflows still using Gemini 2.5 Pro or Gemini 3 Flash
- Switch Gemini 2.5 Pro usage to Gemini 3.1 Pro (Preview), and Gemini 3 Flash usage to Gemini 3.6 Flash
- Copilot Enterprise admins should confirm alternative models are enabled in their model policies under Copilot settings
- Reach out to your GitHub account manager or check the support documentation if you have questions
