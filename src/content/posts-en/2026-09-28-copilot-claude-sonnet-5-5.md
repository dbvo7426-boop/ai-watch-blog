GitHub made Anthropic's Claude Sonnet 5.5 generally available in GitHub Copilot, targeted at well-scoped everyday development work rather than the largest, most complex agentic tasks.

## Details

- **Primary use case**: building features and fixing bugs — well-scoped everyday work
- **Efficiency gain**: matches Claude Sonnet 5's coding performance while using significantly fewer steps, tokens, and tool calls, resulting in faster task completion
- **Supported surfaces**: Visual Studio Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, github.com, mobile apps, and Copilot CLI
- **Eligibility**: Copilot Pro, Pro+, Max, Business, and Enterprise subscribers, with gradual rollout
- **Admin controls**: Business and Enterprise administrators manage access through Copilot settings, with new models enabled by default unless explicitly disabled

## What happened next

Sonnet 5.5's efficiency-first positioning follows the same pattern as GPT-6 Sol/Luna and Claude Opus 5.5 earlier in September — same-quality output at lower token and step cost — continuing the industry's shift toward optimizing everyday coding tasks for cost and speed rather than only chasing higher capability ceilings.
