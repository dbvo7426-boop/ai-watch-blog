GitHub deprecated MAI-Code-1-Flash across all GitHub Copilot experiences effective September 10, 2026.

## Details

- **Deprecated model**: MAI-Code-1-Flash
- **Affected surfaces**: Copilot Chat, inline edits, ask and agent modes, and code completions
- **Recommended replacement**: MAI-Code-1.1-Flash
- **Admin action needed**: enterprise administrators must enable access to MAI-Code-1.1-Flash through their organization's model policies in Copilot settings before it appears in the model selector

## What happened next

The deprecation is routine model-lifecycle housekeeping, continuing GitHub's pattern of retiring superseded models shortly after their successors become available.
