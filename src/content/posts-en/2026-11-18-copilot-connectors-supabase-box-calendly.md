GitHub added eight connectors to Copilot on November 18, 2026, all using GitHub-verified MCP servers. They join more than 25 existing connectors such as Slack, Figma and Sentry, and once connected a service can be used across Copilot.

- Box: search and manage content, and use Box AI
- Buildkite: work with pipelines and builds
- Calendly: manage scheduling and meetings
- ClickUp: track tasks and projects
- Mixpanel: explore product analytics
- Supabase: work with projects and databases
- Webflow: manage sites and content
- Wix: manage sites and business tools

**Status and plans:** public preview, available to all Copilot plans. On Business and Enterprise an admin must enable the Editor preview features policy. Enterprise allowlists that list connectors individually (not by wildcard) need the new connectors added, and some services need an admin to enable access on their side, for example Box MCP access.

**Setup:** in the Copilot app, Customize then Connect; in Copilot CLI, run /mcp, open the Connectors tab and Connect; in VS Code, Agents window then Customizations; on github.com, the Copilot customization page.
