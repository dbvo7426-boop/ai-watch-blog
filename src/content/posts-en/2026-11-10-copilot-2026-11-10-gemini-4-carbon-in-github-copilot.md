Gemini 4 Carbon, Google's latest model, is now generally available in GitHub Copilot. GitHub describes it as designed for complex coding, agentic and reasoning tasks, with an emphasis on secure code generation and security-focused work.

## Details

- **Plans:** Copilot Pro+, Max, Business and Enterprise. Copilot Pro is not listed.
- **Where to select it:** the model picker in Visual Studio Code, Visual Studio, Copilot CLI, the GitHub Copilot coding agent, the GitHub Copilot app, github.com, GitHub Mobile (iOS and Android), JetBrains IDEs, Xcode and Eclipse.
- **Rollout:** gradual, so some users may not see the model yet.
- **Billing:** usage-based billing at provider list pricing. A premium request multiplier is not stated; GitHub points to its Models and pricing documentation.
- **Admin control:** Business and Enterprise administrators control access through the model policy in Copilot settings. Under default model enablement, new models are turned on automatically unless an administrator has disabled the global default or turned off this model specifically.

The model's original announcement is covered in our Gemini 4 Carbon article of October 28.
