GitHub announced a batch of model deprecations taking effect October 19, 2026 across all GitHub Copilot experiences.

## Details

- **Deprecated models and their replacements**: Gemini 3.7 Flash → Gemini 3.8 Flash; GPT-5.5 → GPT-5.6 Sol; GPT-5.4 → GPT-5.6 Sol; GPT-5.4 mini → GPT-5.6 Luna; GPT-5 mini → GPT-5.6 Luna; Grok 4.5 → Grok 4.6
- **Affected surfaces**: Copilot Chat, inline edits, ask and agent modes, and code completions
- **Action needed**: users should update workflows and integrations to use the supported models before the deprecation date
- **Enterprise handling**: for Business and Enterprise customers, suggested alternatives activate automatically unless administrators have disabled default model enablement; deprecated models are removed automatically after the cutoff with no manual action required

## What happened next

The deprecation batch is broader than GitHub's typical single-model retirements, clearing out older Gemini, GPT, and Grok versions in one pass roughly six weeks ahead of the cutoff, giving teams a longer runway than usual to migrate workflows onto current-generation models.
