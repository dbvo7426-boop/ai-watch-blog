GitHub made Anthropic's newly launched Claude Haiku 5.5 model available in GitHub Copilot, describing it as suited for fast, high-volume work like subagents, quick edits, and terminal tasks.

## Details

- **Performance claim**: in GitHub's testing, Haiku 5.5 matched Claude Sonnet 5's results on many coding tasks while using significantly fewer tokens and steps
- **Availability**: rolling out to Copilot Pro, Pro+, Max, Business, and Enterprise plans across Visual Studio Code, Visual Studio, Copilot CLI, GitHub.com, JetBrains IDEs, Xcode, and Eclipse, with a gradual rollout
- **Pricing**: billed at provider list pricing under usage-based billing, with exact rates published in GitHub's models and pricing documentation
- **Admin controls**: Business and Enterprise plan administrators can manage access via model policies in Copilot settings; new models are enabled by default unless an administrator disables them
- **Feedback channel**: GitHub is directing user feedback to its Community discussions forum

## What happened next

The same-day rollout of Haiku 5.5 into Copilot mirrors the pattern set by Sonnet 5.5's earlier GA in Copilot, underscoring how tightly GitHub's model lineup now tracks Anthropic's release cadence — giving Copilot users a cheaper, faster option for the high-frequency subagent and terminal work that previously ran on costlier models.
