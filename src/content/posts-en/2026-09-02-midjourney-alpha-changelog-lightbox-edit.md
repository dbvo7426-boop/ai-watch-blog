Midjourney published an alpha changelog dated September 2, 2026, folding its recently launched V8.2 edit model directly into the lightbox viewer and rolling out an experimental "Change Style" option, alongside a broad set of speed and bug fixes on the alpha.midjourney.com build.

## Details

- **Edit model in the lightbox**: the V8.2 edit model now has an integrated editor inside the lightbox — open any image, edit it with plain-language instructions, attach up to four reference images, and see every edit made in that session collected in one place
- **Experimental Change Style**: a new "Change Style" option is rolling out experimentally in the lightbox, part of what Midjourney describes as a broader push to simplify style customization
- **Drag-and-drop refinement**: continued tuning of the drag-and-drop interaction, which the team says still needs visual polish
- **Prompt bar and pills fixes**: several bug fixes and quality-of-life tweaks to the prompt bar, though Midjourney says it hasn't yet decided how default parameters should persist across sessions
- **Speed and stability**: general performance improvements, fixes for overlapping UI elements, a fix for Niji 7 no longer conflicting with inpainting, removal of a stray Pinterest extension button in the sidebar, and clearer error messaging
- **What's next**: Midjourney lists default parameter settings, an sref preview alongside prompts, more on-screen room for images, and a clearer way to close the settings panel as upcoming alpha work

## What happened next

This is the third alpha-focused update to the V8.2 edit workflow in under a week, following the model's August 27 debut and an August 29 quality patch — both changes so far have landed on the alpha build before any wider rollout is confirmed. Midjourney continues to treat alpha.midjourney.com as a live testbed, shipping incremental UI and reliability fixes while it decides which experimental features, like Change Style, are ready to graduate more broadly.
