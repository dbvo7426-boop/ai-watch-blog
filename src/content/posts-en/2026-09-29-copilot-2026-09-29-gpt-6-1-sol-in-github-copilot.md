GitHub began rolling out OpenAI's newly launched GPT-6.1 Sol model in GitHub Copilot, citing strong agentic coding and terminal-workflow performance delivered with substantially fewer tokens and steps than prior GPT-6 and GPT-5.6 models.

## Details

- **Strengths**: agentic coding and terminal workflows with strong multistep coding performance
- **Efficiency**: uses substantially fewer tokens and processing steps compared to earlier GPT-6 and GPT-5.6 versions
- **Availability**: rolling out to Copilot Pro+, Max, Business, and Enterprise subscribers across VS Code, Visual Studio, JetBrains IDEs, Xcode, Eclipse, github.com, iOS/Android mobile apps, and the Copilot CLI
- **Pricing**: billed at provider list pricing under usage-based billing
- **Admin controls**: Business and Enterprise administrators can manage access via model policies in Copilot settings; the model is enabled by default unless explicitly disabled

## What happened next

This GA rollout landed the same day as GPT-6.1 Sol's main launch and OpenAI's "dots" announcement at DevDay 2026, continuing the same-day cross-platform release pattern GitHub and OpenAI used previously with Claude Sonnet 5.5.
