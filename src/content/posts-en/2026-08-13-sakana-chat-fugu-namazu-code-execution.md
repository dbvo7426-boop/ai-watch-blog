Sakana AI has updated Sakana Chat — its free, API-free web platform at chat.sakana.ai for using its models directly — to add its Fugu orchestrator model and a new-generation Sakana Namazu, plus sandboxed Python code execution and file attachment support.

## Details

- **Sakana Fugu added**: The orchestrator model, which Sakana says performs on par with frontier models, is now available directly in Sakana Chat. It's aimed at complex instructions and multi-step tasks where output quality determines whether the result is usable
- **Sakana Namazu upgraded**: The Japanese-focused model has been refreshed to a new generation that Sakana says improves both Japanese response quality and agentic execution over the version that launched as a paid API on August 3. It's built to take Japanese instructions as given and return natural Japanese documents and materials, aimed at recurring workplace tasks
- **Python code execution**: Previously, Sakana Chat's models could only return text answers. Models can now execute Python in a sandbox to handle calculations, data processing, and file generation on their own
- **Deliverables with live preview**: Generated outputs now display in a side panel with a live preview, and users can download results or ask for revisions within the same conversation instead of starting over
- **File attachments**: All models in Sakana Chat now accept image attachments, plus PDFs and Office documents (Word, slide decks), enabling workflows that combine document analysis with code execution
- **Availability**: The update went live August 13, 2026 at chat.sakana.ai; no pricing changes were disclosed

## What happened next

This brings Sakana AI's two flagship models — the frontier-class Fugu orchestrator and the Japanese-specialized Namazu — into the same free consumer surface for the first time, rather than requiring API access. The addition of sandboxed code execution and downloadable deliverables also moves Sakana Chat closer to an agentic, task-completing tool rather than a plain question-answering chatbot.
