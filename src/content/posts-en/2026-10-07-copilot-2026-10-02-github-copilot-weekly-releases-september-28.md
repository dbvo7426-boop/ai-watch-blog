GitHub published its weekly Copilot release roundup for the week of September 28, consolidating several model and workflow updates.

## Details

- **New models**: Claude Sonnet 5.5 became available across Copilot Pro through Enterprise tiers; GPT-6.1 Sol access extended to Pro+ and higher tiers
- **HydraFusion**: a research preview letting Copilot select and coordinate multiple models for a task, now in VS Code and the Copilot app, with enhanced progress tracking
- **Dynamic Workflows**: reusable automation that lets users record Copilot tasks for repeated execution, supporting release checks and failure investigation with review pauses
- **Computer use automation**: desktop app automation on macOS and Windows via Copilot CLI and app, letting Copilot navigate and manipulate desktop applications with user approval controls
- **Azure Canvases**: three interactive workspace tools for Azure resource exploration, cost analysis, and Functions management, installable via the Awesome Copilot marketplace
- **VS Code improvements**: experimental multi-folder sessions enabling a single agent to work across multiple project directories, and worktree folder reuse to cut redundant dependency installs

## What happened next

This roundup bundles several items — HydraFusion, Dynamic Workflows, and computer use — that this blog already covered individually when they shipped; the weekly digest format mainly adds the Azure Canvases and VS Code multi-folder/worktree improvements as genuinely new items, continuing GitHub's cadence of weekly release summaries alongside standalone changelog posts for bigger features.
