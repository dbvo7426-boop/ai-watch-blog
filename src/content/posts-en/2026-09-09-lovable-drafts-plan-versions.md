Lovable's September 9, 2026 changelog focused on giving builders safer ways to experiment and track changes, alongside a couple of interface cleanups.

## Details

- **Explore changes with drafts**: users can now create a separate copy of a project to test ideas without affecting the main version, then merge or discard the draft afterward
- **Compare and restore plan versions**: Lovable's planning feature now keeps a revision history, letting users browse past versions of a plan, compare them, and restore an earlier one
- **Redesigned Chat actions menu**: the actions menu inside project chat has been reorganized into grouped sections with a search function, replacing a flatter list
- **Readable CSV/TSV previews**: files attached to chat in CSV or TSV format now render as formatted tables with visible row and column headers instead of raw text

## What happened next

Drafts and plan-version history both address the same underlying concern — giving builders a safety net when trying something that might not work out, rather than forcing them to commit changes directly to a live project. The changes continue a run of version-control-style features Lovable has been adding through September. Full details are in Lovable's official changelog at docs.lovable.dev/changelog.
