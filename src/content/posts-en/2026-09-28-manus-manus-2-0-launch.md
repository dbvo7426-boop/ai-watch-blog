Manus released Manus 2.0 on September 28, 2026, describing it as a rebuild of the product's foundations rather than an incremental update. The release bundles a new agent architecture called Cascade, an always-on hosting product called Cloud Computer, event-triggered Automations, a professional creation workspace called Manus Studio, and a separate standalone app called Cue for personal agents.

## Details

- **Cascade agent harness**: Manus's new in-house architecture keeps a project lightweight at the start and attaches specialized capabilities only as work demands them, so a brief, a landing page, a video cut, and an automation can stay part of one connected project instead of scattering across separate chats. In tested configurations, Manus says Cascade used 23.2% fewer tokens, finished tasks in 28.2% less time, and cost 32% less to run than its previous system
- **Cloud Computer**: a dedicated, persistent hosting environment for projects that need always-on infrastructure, such as multiplayer games or continuously running automations
- **Automations**: upgraded from simple scheduled tasks to event-driven workflows that can kick off work in response to an incoming email, a calendar update, a Slack message, or a Notion change, all configured from a single prompt
- **Manus Studio**: a shared desktop workspace with specialized modes, including a video editor for 30-60 second short-form content (ads, tutorials, vlogs) with an "Alchemy mode" for AI-directed edits, a Game Dev environment with built-in multiplayer support via Cloud Computer, and remote/voice control of a desktop computer from a phone
- **Cue**: a new standalone personal-agent app for web, desktop, and mobile that gives each agent its own identity, including a personal email address, phone number, and wallet, with support for multi-agent teams and everyday-service integrations like restaurant QR codes; Cue is opening in early access via invite code MEETCUE on a first-come, first-served basis, with the iOS version still pending App Store review
- **Availability**: Manus 2.0 itself is live immediately across web, desktop (macOS/Windows), and mobile (iOS/Android); Manus did not disclose new pricing alongside the release

## What happened next

The update lands about a month after Manus resumed independent operations following its separation from Meta, and it doubles as a statement that the company is investing heavily in its post-split roadmap rather than treading water. By pairing efficiency gains in the core agent harness with new persistent-hosting and consumer-facing personal-agent products, Manus is pushing beyond one-off task completion toward always-on agents that live inside a user's daily workflow and personal life. Uptake of Cue in particular, gated behind an invite code, will be an early signal of how much demand exists for agents with their own contact information and spending ability.
