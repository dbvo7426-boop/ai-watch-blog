GitHub rolled out general availability of Google's Gemini 4 Argon in GitHub Copilot.

## Details

- **Performance**: in early testing, Gemini 4 Argon solved more tasks than previous Gemini models on every coding benchmark, with its largest gains showing up in Copilot CLI; it also tests edge cases before finishing a task
- **Pricing**: billed at provider list pricing under usage-based billing
- **Availability**: Copilot Pro+, Max, Business, and Enterprise users can select it in the model picker, with a gradual rollout meaning it may not appear for everyone immediately
- **Admin controls**: Business and Enterprise administrators can manage access through model policy in Copilot settings; new models are enabled by default unless an administrator disables them
- **Platforms**: Visual Studio Code, Visual Studio, Copilot CLI, GitHub Copilot coding agent, the GitHub Copilot app, JetBrains IDEs, Xcode, and Eclipse

## What happened next

This GA rollout landed the same day as Gemini 4 Argon's broader global availability push across Google's own API, Gemini app, and developer tools, continuing the established same-day cross-platform pattern GitHub has followed with prior frontier model launches like Claude Sonnet 5.5 and GPT-6.1 Sol.
