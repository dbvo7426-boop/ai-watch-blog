GitHub published its September 2026 changelog for GitHub Copilot in VS Code, spanning versions 1.136 through 1.140, with a cluster of agent-workflow and integration improvements.

## Details

- **Agents window**: HydraFusion-based automatic model/workflow selection (research preview); recurring automations that can be scheduled hourly, daily, or weekly, or run on demand from templates; "Agent Merge," which uses HydraFusion to handle review feedback and merge conflicts; direct pull request creation from agent sessions with editing options; hierarchical session navigation between related chats; session cleanup with automatic archiving; application badges surfacing pending results and PR checks (preview); and dev container support for launching agent sessions with project-configured tools
- **Workspaces and environments**: flexible chat attachment that lets a general chat be narrowed to a specific project by adding local folders later; cross-app continuity that carries Codex conversations from ChatGPT directly into VS Code without manual context transfer
- **Chat and integrations**: non-interrupting agent messages that no longer break an active conversation turn; direct embedding of GitHub issues and PRs via URL or context menu

## What happened next

The release cluster shows GitHub converging Copilot's VS Code experience around the same themes as its CLI and app updates this week — HydraFusion-style multi-model coordination, scheduled/recurring automation, and tighter cross-product continuity with OpenAI's Codex — ahead of the computer-use and dynamic-workflows features that shipped the same month.
