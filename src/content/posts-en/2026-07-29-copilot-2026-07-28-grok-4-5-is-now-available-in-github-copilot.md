GitHub has added Grok 4.5, xAI's latest reasoning model, to GitHub Copilot. Designed for fast, agentic coding and complex multi-step workflows, it's rolling out gradually across VS Code, Copilot CLI, and other major development surfaces.

## Details

- **Overview**: xAI's latest reasoning model, designed for fast agentic coding and complex multi-step workflows
- **Context window**: 500,000 tokens
- **Input types**: Supports both text and image input
- **Reasoning effort**: Selectable across three levels — low, medium, and high
- **Performance**: Internal testing showed strong results on terminal-based coding tasks in VS Code and Copilot CLI. The model is particularly good at dispatching tools in parallel and taking direct action, making it well suited to exploratory work, unblocking complex tasks, and time-sensitive coding workflows
- **Eligible plans**: Copilot Pro, Pro+, Max, Business, and Enterprise
- **Supported surfaces**: Visual Studio Code, Visual Studio, Copilot CLI, the GitHub Copilot cloud agent, the GitHub Copilot app, JetBrains, Xcode, and Eclipse
- **Billing**: Billed at the provider's API list price under usage-based billing
- **Rollout**: Gradual rollout starting July 28, 2026. Business and Enterprise administrators must manually enable the Grok 4.5 policy in their organization's Copilot settings, since it's off by default

## How to try it

- On an eligible plan where the rollout has reached you, select "Grok 4.5" from the model picker in any supported editor or app
- Business/Enterprise administrators must first enable the corresponding policy (off by default) in their organization's Copilot settings
