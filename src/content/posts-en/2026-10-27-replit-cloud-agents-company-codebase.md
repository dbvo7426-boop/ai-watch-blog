Replit announced on October 27, 2026 (page updated October 29) that anyone on a team can use Replit Cloud Agents to contribute code to a company's core codebase while engineers keep control of what ships. Replit frames it as part of its Self-Driving Company vision.

## Details

- **Availability:** Cloud Agents for existing repositories are available to all Pro and Enterprise customers. The Slack integration is available to all customers. Repositories connect at replit.com/repos.
- **Workflow:** a user describes a change in plain language; the agent finds the code, makes the change while a live preview updates, and opens a pull request in GitHub or a merge request in GitLab following team skills and contribution guidelines. It applies review feedback, human or agent, to the same request.
- **Testing:** the agent tests the change in an isolated cloud sandbox by clicking through the running app in a browser, fixes failures, and attaches screenshots and video to the pull request.
- **Shared environments:** an admin sets up a VM once with repos, runtimes, skills, tools and dependencies, which updates from the main branch. Credentials come from external secrets managers through a credential broker.
- **Slack:** mentioning or DMing @Replit can investigate an issue or turn a proposal into a pull request. Microsoft Teams support is described as coming soon, and pull requests can also start from the mobile app.
- **Workspace memory (early access):** review feedback worth keeping becomes a proposed update to team skills, which engineers approve before it takes effect. Replit reports internal use cut token usage by 51% and a common data task from 16 minutes to 1 minute.
- **Webinar:** a webinar is scheduled for November 5.

## What happened next

The approach shifts feature requests from tickets to pre-tested pull requests, but approval stays with engineers. Pricing beyond the Pro and Enterprise plans is undisclosed, and the internal efficiency figures are Replit's own.
