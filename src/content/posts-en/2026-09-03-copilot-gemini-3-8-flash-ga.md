GitHub added Gemini 3.8 Flash, Google's newest Flash-tier model, to GitHub Copilot, just one day after Google released it alongside the more restricted Gemini 3.8 Flash Cyber variant.

## Details

- **What's new**: GitHub says its early testing found Gemini 3.8 Flash improves on its predecessor's coding performance, consistent with Google's own benchmark claims for the model on software-engineering tasks
- **Timing**: the Copilot integration landed the day after Google's public release of 3.8 Flash, continuing GitHub's pattern of fast-following new frontier model launches from multiple providers

## What happened next

Administrators can enable Gemini 3.8 Flash through their Copilot model policies, giving users access to Google's latest Flash-tier model alongside Copilot's existing lineup from Anthropic, OpenAI, and others.
