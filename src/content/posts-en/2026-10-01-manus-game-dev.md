Manus launched Game Dev on October 1, 2026, a tool aimed at letting people with no coding background build games with AI, as part of the Manus Studio desktop workspace.

## Details

- **Tweak Panel**: lets creators adjust gameplay parameters in real time while the game is running, such as speed, gravity, damage, and spawn rate, without touching code or restarting the game
- **Assets management**: an interface for swapping, replacing, and AI-editing game assets, including characters, visuals, animations, effects, and sound, so creators can personalize gameplay without technical skills
- **Built-in multiplayer**: Game Dev handles server deployment and networking automatically, so creators can ship multiplayer games without managing infrastructure themselves
- **Acknowledged rough edges**: co-founder Tao Zhang said Manus 2.0 "still has quite a few rough edges" and that the team will keep refining Game Dev, framing the tool as a complement to, not a replacement for, human creativity
- **Availability**: Game Dev is available now via the Manus Studio desktop app, with download links for macOS, Windows, iOS, and Android; no specific pricing was disclosed

## What happened next

Like Manus's new Video Editor, Game Dev turns a capability that was only briefly namechecked in the September 28 Manus 2.0 announcement into a fully detailed, standalone launch. Pairing a no-code tweak interface with automatic multiplayer infrastructure targets a specific pain point — the server and networking work that normally keeps non-programmers out of multiplayer game creation — and signals Manus Studio is becoming a broader creative suite rather than a single-purpose agent chat.
