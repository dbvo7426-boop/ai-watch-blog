GitHub added MAI Code 2 and MAI Code 2 Flash to GitHub Copilot on November 17, 2026. Both are built for agentic coding workflows.

- **MAI Code 2**: a general-purpose coding model for complex work such as deep debugging, multi-file implementation, refactoring and repository-wide reasoning.
- **MAI Code 2 Flash**: a lightweight, cost-efficient model for everyday tasks such as code explanations, targeted edits, routine fixes and rapid iteration.

**Plans:** MAI Code 2 is available on Copilot Pro, Pro+, Max, Business and Enterprise. MAI Code 2 Flash is available on Free, Student, Pro, Pro+, Max, Business and Enterprise. Both are available to eligible subscribers on annual plans.

**Where:** the model picker in Visual Studio Code, Visual Studio, Copilot CLI, the Copilot cloud agent, the Copilot app, github.com, GitHub Mobile (iOS and Android), JetBrains, Xcode and Eclipse.

**Billing and admin:** both use usage-based billing; request multipliers are not listed in the announcement, which points to the Models and pricing documentation. Business and Enterprise admins manage access through the model policy in Copilot settings. Under default model enablement, new models turn on automatically unless an admin disabled the global default or the model.
