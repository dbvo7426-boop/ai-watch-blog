Lovable's September 23, 2026 changelog entry lets apps built on the platform call Anthropic's Claude models for their own AI features without developers supplying separate API credentials, alongside a batch of connector, security, and dashboard updates.

## Details

- **Built-in Claude access**: apps can use Claude Fable 5.1, Claude Opus 5.5, Claude Opus 5, Claude Sonnet 5, and Claude Haiku 4.5 for chatbots, document analysis, image examination, PDF field extraction, and structured outputs, with no separate Anthropic API key required
- **Availability**: limited for now to apps created after May 13, 2026 that use the TanStack Start framework
- **Five new connectors**: AWS API, Azure Cloud API, Azure Graph & Entra API, Google Cloud API, and Looker, letting apps reach those cloud and analytics services without being hosted on them
- **Extended-retention models for Enterprise**: workspace admins can enable access to more capable models whose providers retain data for 30+ days before deletion, under data-protection settings
- **Database cost estimation**: the instance management dialog now shows estimated monthly Cloud costs in credits for each database size option
- **Usage tracking split**: image and video generation now appear separately in build-credit usage details
- **Security view redesign**: project security findings are now grouped by area, with risks explained in plain language alongside the technical evidence
- **Dashboard and mobile refinements**: a new projects-page toolbar with consolidated filtering, a single consolidated project menu on mobile, and typo-tolerant connector search

## What happened next

The update follows Lovable's September 22 addition of a Parallel connector for cited web research, continuing a steady weekly cadence of changelog entries. Bundling first-party Claude model access with the connector and security updates gives Lovable-built apps more built-in AI capability and enterprise-grade data controls without extra setup from developers.
