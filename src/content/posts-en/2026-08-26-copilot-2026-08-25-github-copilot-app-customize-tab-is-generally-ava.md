GitHub has announced that the Customize tab inside the GitHub Copilot app is now generally available, giving teams a unified place to tailor Copilot to the tools and workflows they already use.

## Details

- **What it is**: The Customize tab consolidates MCP servers, plugins, skills, and canvases into a single interface within the GitHub Copilot app
- **Discovery features**: Users can browse featured customizations curated from each category, and find MCP servers faster by exploring trending options or browsing by category
- **Canvases**: Featured canvases are designed to help teams move from planning straight into execution — for example, an Azure DevOps canvas lets users triage issues, prioritize backlogs, assign follow-ups, and hand work directly to Copilot
- **Example integrations shown**: The announcement's screenshots highlight customizations for Figma, Impeccable Design, and Microsoft Foundry
- **Availability**: General availability, with no preview phase mentioned and no specific pricing-tier restriction called out
- **How to access it**: Open the GitHub Copilot app and select the Customize tab

## How to try it

- Open (or install) the GitHub Copilot app
- Select the **Customize** tab
- Browse featured MCP servers, plugins, skills, and canvases, or search by category to find integrations relevant to your team's stack
- Try a featured canvas, such as the Azure DevOps canvas, to move work from planning to execution without leaving Copilot
