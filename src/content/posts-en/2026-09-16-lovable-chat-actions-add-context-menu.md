Lovable's September 16, 2026 changelog entry reorganizes the chat actions menu inside projects, folding everything a user can attach to a message into a single grouped menu.

## Details

- **One "Add context" group**: the chat actions menu — opened via the "+" button next to the chat input in a project — now consolidates skills, other projects, connectors, designs, screenshots, and files into a single group instead of scattering them across the menu
- **Same access via shortcuts**: typing "@" or "/" opens the same menu, landing on context or skills respectively
- **Desktop detail panel**: on desktop, highlighting a skill, project, or connector in the menu now shows a details panel for that item
- **Goal listed as a skill**: Lovable's "Goal" feature appears in the menu among the skills built by Lovable

## What happened next

The change is a UI consolidation rather than a new capability, tidying up a menu that had grown as Lovable added more things a user could attach to a chat message — skills, connectors, and design/file references among them. It follows closely on Lovable's mid-September connector and multi-model additions, continuing a pattern of frequent, incremental changelog updates as the project's chat interface accumulates more integrations.
