Cursor shipped Remote Control for Local Agents on October 6, 2026, letting users monitor and reply to agents running locally on their desktop from the Cursor iOS app, without routing the work through a cloud agent.

## Details

- **What it does**: the Cursor iOS app can now see and reply to local agents running on a user's own computer, extending mobile access beyond cloud agents to local sessions
- **Setup**: users download the Cursor iOS app, sign in, and their connected computers appear automatically; tapping a computer sends a pairing request that must be approved from the desktop app
- **Usage**: once paired, local agents appear in a list in the iOS app, where users can view status and send them messages remotely
- **How it works**: agents keep running on the user's own machine — the app only connects to them; the computer must stay powered on and connected to the internet for the connection to work
- **Staying awake**: a "Keep this computer awake" option in desktop settings prevents sleep mode, though it requires the machine to be plugged in with the lid open
- **Availability and controls**: Remote Control is on by default for all users except Enterprise organizations, where admins can toggle it from Org settings under Security and identity

## What happened next

The feature closes a gap between Cursor's cloud agents, which have long been reachable from mobile, and local agent sessions tied to a specific desktop. By letting a phone pair directly with a running desktop instance, Cursor gives users a way to check on and steer in-progress local work without needing to migrate it to the cloud first or sit at their computer.
