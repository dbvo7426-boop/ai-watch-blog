Perplexity introduced Automations in Perplexity Computer on September 29, 2026, giving the agent a way to handle ongoing, recurring work instead of starting fresh on every request. Users can hand Computer a standing assignment once, and it keeps running it on its own.

## Details

- **Two trigger types**: Automations fire either on a fixed schedule or in response to events from connected apps including Slack, Gmail, Outlook, Linear, and GitHub
- **Memory across runs**: each run carries context from prior runs, so Computer can compare new findings against earlier ones — for example, a weekly pricing report can call out what changed since last week
- **Missed-item detection**: users can configure alerts for overdue updates or unmet deadlines, with Computer flagging items that need attention based on job history
- **Setup**: Automations are created by describing the assignment in Computer's omnibar or through a dedicated Automations interface, with support for custom permissions and review requirements before actions are taken
- **Billing**: credits are only spent when Computer actually runs an assignment, not while it's idly waiting to be triggered
- **Migration**: existing Scheduled Tasks can be migrated to the new Automations surface, and the feature is available to all Computer users

## What happened next

Automations turns Perplexity Computer from a tool that answers one-off requests into one that can own standing responsibilities — monitoring inboxes, tracking competitor pricing, or watching for overdue tickets — without a person re-prompting it each time. The launch follows Perplexity's steady push through 2026 to make Computer a persistent agent with memory and broader integrations, rather than a single-session assistant.
