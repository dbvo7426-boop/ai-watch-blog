Enterprises working with a GitHub or Microsoft account team can now get Copilot included with GitHub Enterprise for every licensed user. Instead of managing seat counts and usage separately, usage against the enterprise budget becomes the main thing to manage.

## Details

- **Features:** Same features and models as Copilot Enterprise, but no monthly AI credits per seat.
- **Standalone option:** Users in the enterprise without a GitHub Enterprise license get the same access through Copilot Standalone at $10 per user per month.
- **Metering:** AI usage is metered from the first request against the enterprise budget, using existing policies, alerts, and attribution. There is no included allowance to track or top up.
- **Budget exhausted:** Code completion and next edit suggestions keep working with no budget. Copilot Chat, code review, and Copilot in the cloud need available budget. Access (the seat) is never removed.
- **Availability:** Available now for GitHub Enterprise Cloud via a GitHub or Microsoft account team. Self-serve is coming in stages with dates to be shared in the coming weeks; current self-serve subscriptions are unaffected. Copilot Business and Copilot Enterprise remain available to buy.

## What happened next

This turns Copilot from an add-on seat into part of the platform license, with consumption-based cost control. Procurement simplifies, but budget owners lose the predictability of a bundled credit allowance, so budget alerts matter more. Self-serve timing is undisclosed beyond the coming weeks.
