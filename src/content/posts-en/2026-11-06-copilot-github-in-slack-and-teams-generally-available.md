`@GitHub` in Slack and Teams is now generally available. From a conversation you can investigate bugs, create issues, implement changes, and open pull requests without leaving the chat.

## What's new

- **Canvas in Teams:** Review implementation plans, code changes, and previews alongside the conversation, share feedback with teammates, and refine the implementation together in Teams.
- **Faster onboarding:** `@GitHub` identifies the repository from your message and starts the session without asking you to select it again. Getting started is also easier when you are not signed in, have no default repository, want to switch repositories, or need app access.
- **More reliable conversations:** A fix for an issue that could block responses to follow-up messages.
- **Clearer attribution:** Issues and pull requests created by `@GitHub` now say in their description that they were created from a Slack or Teams conversation with the user's name.

## What happened next

An October update to the Slack and Teams integration added model and repository selection; this release brings it to general availability. Plan availability and pricing are not disclosed in the announcement.
