xAI announced that its coding model, Grok 4.5, is now available in GitHub Copilot for millions of developers who use VS Code and GitHub products every day, selectable directly from the model picker.

## Details

- **Availability**: Grok 4.5 can be selected from the model picker across GitHub Copilot's interfaces, including the VS Code IDE, Copilot CLI, and cloud agents. Some organizations may require administrator approval to enable the option
- **Model characteristics**: Designed for fast, agentic coding and complex multi-step workflows, with a context window of up to 500,000 tokens, support for text and image inputs, and a choice of low, medium, or high reasoning effort
- **Performance**: In xAI's internal testing, Grok 4.5 showed strong results on terminal-based coding tasks in VS Code and Copilot CLI, performing especially well when dispatching multiple tools in parallel and taking direct action — making it a good fit for exploration, unblocking complex tasks, and time-sensitive coding work
- **Pricing**: Via xAI's console, it's billed at $2 per million input tokens and $6 per million output tokens. Within GitHub Copilot, it's billed under usage-based pricing
- **Available plans**: Copilot Pro, Pro+, Max, Business, and Enterprise SKUs

## How to try it

- Select "Grok 4.5" from the model picker in GitHub Copilot (VS Code, Copilot CLI, or cloud agents)
- Organization accounts may need an administrator to approve enabling the model in Copilot settings
- Best suited for complex coding tasks involving parallel tool calls or time-sensitive work
