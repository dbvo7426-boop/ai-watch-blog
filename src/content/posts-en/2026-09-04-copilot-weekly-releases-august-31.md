GitHub published its week-of-August-31 Copilot release roundup, covering model expansions, a security enhancement, and new VS Code agent features.

## Details

- **Model expansions**: Claude Fable 5.1 became available to Copilot Pro+, Max, Business, and Enterprise subscribers, while Gemini 3.8 Flash rolled out to Pro, Pro+, Max, Business, and Enterprise users
- **Security**: the Copilot app and CLI now honor content exclusion policies, keeping sensitive code out of context across agentic workflows
- **JetBrains**: the Copilot harness reached general availability in Copilot for JetBrains, aimed at faster feature rollouts and improved code quality
- **VS Code 1.136**: Agent Merge entered public preview, automating pull request preparation by handling review comments, test failures, and conflicts; multi-root workspace support for agent sessions moved to experimental; chat background customization (patterns/images) became experimental; and a new chat sessions view organizes conversations hierarchically and flags ones needing attention

## What happened next

The roundup lands the same week Claude Fable 5.1 and Gemini 3.8 Flash both reached Copilot, continuing GitHub's pattern of bundling multi-provider model rollouts with incremental IDE and security improvements in a single weekly digest.
