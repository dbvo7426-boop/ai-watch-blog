Suno pushed a significant overhaul of playlists across web, iOS, and Android, adding shuffle, creator-based filtering, in-playlist search, and custom cover art — then followed it up the next day with offline playlist downloads for mobile.

## Details

- **Shuffle**: Playlists can now be shuffled on web, with a mobile version of shuffle noted as coming later
- **Creator filters**: Users can filter playlists by creator type — user-created, Suno-created, or third-party creator — making it easier to find the right kind of playlist in the Library and Explore tabs
- **Playlist management**: Songs within a playlist can be reordered and added directly, and playlists can be added to a user's personal library with one action
- **Library navigation**: Liked playlists can be viewed as a grid or a list, songs can be searched for within a single playlist or across all playlists, and playlists can be pinned to the top of the library (web only for pinning)
- **Custom cover art**: Playlists now show smarter auto-generated cover art pulled from the songs inside them, or users can generate their own custom cover
- **Offline playlists (shipped one day later, Aug 20)**: iOS and Android users can now save playlists for offline listening, so playback continues without a network connection

## What happened next

- Both updates are live now — the playlist overhaul on web, iOS, and Android as of August 19, and offline playlist downloads on iOS and Android as of August 20
- Mobile shuffle support is still pending, per Suno's own release notes
- Full changelog entries are published on Suno's official release notes page at suno.com/release-notes
